AVINASH SINGH RATHORE — GRAPHIC DESIGN PORTFOLIO

HOW TO VIEW
1. Extract this folder if it is zipped.
2. Double-click index.html to open it in Chrome/Edge.

PUBLISH ONLINE
- Upload the contents of this folder to a GitHub repository.
- In repository Settings > Pages, select Deploy from a branch and choose main / root.

IMPORTANT CUSTOMIZATION
- Replace hello@example.com in index.html with your actual email address (search/replace both occurrences).
- Add your Instagram / Behance / LinkedIn links if you want them shown.
- The portfolio images are extracted from the PDF you supplied.
- Google Fonts need an internet connection; the site still works offline with fallback fonts.
